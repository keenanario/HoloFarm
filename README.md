# HoloFarm

HoloFarm is a virtual reality based agricultural education application, especially farming designed to address the challenge to educate users about farming techniques and jargons in urban cities. Player needs to complete serial task of farming and deliver the crops according to the requirement order in the tablet.

## Requirements
To run HoloFarm, you will need the following:

### Software Requirements:
* Unity 2022.3.22f or later.
* For Windows User, install Meta Quest Link App from [here](https://www.meta.com/gb/quest/setup/).

### Hardware Requirements:
* VR Devices, the current code tested on Oculus Quest 2.
* A VR-ready PC, for open the code and running the app through Meta Quest Link.

## How to Run the App
To run HoloFarm, you will need to follow these steps:

1. **Set up VR device**:
   * Make sure your device is set up and paired with PC.
   * Install the Meta Quest Link if you use any Meta VR devices.
   * Enable developer mode for the VR device if you plan to sideload the app for testing.
     
2. **Connect the VR device to your PC**:
   * Use either cable or wi-fi to connect your device.
   * If you use Meta VR device, ensure your device is connected and detected by the Meta Quest Link app.
   
3. **Build the App from Unity**
   * Open the HoloFarm project in Unity.
   * Go to `File > Build Settings`.
   * Select the **Android** platform.
   * Ensure the VR device is detected on Unity.
   * Build and run the project to the VR device.
